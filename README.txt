УСТАНОВКА (один раз):
  pip install flask requests playwright pandas
  playwright install chromium

ЗАПУСК:
  python app.py

ОТКРЫТЬ В БРАУЗЕРЕ:
  Ты:          http://localhost:5000
  Коллеги:     http://[IP этого ПК]:5000

  Узнать свой IP: ipconfig → IPv4 Address

НАСТРОЙКА (кнопка ⚙️ в интерфейсе):
  - Папка скриншотов
  - Папка с данными
  - Путь к auth.json
  - Google Safe Browsing API Key

КАК ПОЛУЧИТЬ Google API Key (бесплатно):
  1. console.cloud.google.com
  2. Создать проект
  3. APIs & Services → Enable APIs
  4. Найти "Safe Browsing API" → включить
  5. Credentials → Create API Key

ПОРЯДОК РАБОТЫ:
  1. Получить ссылки (OpenPhish или свой TXT)
  2. Сделать скриншоты
  3. Загрузить в Кибернадзор
  — ИЛИ —
  Нажать ⚡ Всё сразу
